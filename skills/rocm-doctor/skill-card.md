# Skill Card

## Description

Diagnoses ROCm / HIP SDK / PyTorch / llama.cpp failures on AMD GPUs (Linux,
Windows, and WSL2) against a closed list of known misconfigurations, including two
print-only vLLM startup failures on Linux and WSL2 (running out of GPU memory, an
engine import error), and applies a low-risk fix with consent or routes the user
to the right upstream channel.
