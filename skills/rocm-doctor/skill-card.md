# Skill Card

## Description

Diagnoses ROCm / HIP SDK / PyTorch / llama.cpp failures on AMD GPUs (Linux,
Windows, and WSL2) against a closed list of known misconfigurations, and applies a
low-risk fix with consent or routes the user to the right upstream channel, and
covers two vLLM startup failures (running out of GPU memory, an engine import
error) on Linux and WSL2.
